# HP Merge Practice

A playable mobile-web prototype: craft a Wand, write a Spellbook, merge Fire and drag prepared spells to classroom targets.

Japanese and English are available. The first lesson includes an illustrated classroom, painted items and character spell animations.
The game is in development; visual feedback and real-device testing are ongoing.
Progress is stored in this browser and is separate from any localhost save.

This repository contains the built website for GitHub Pages.
