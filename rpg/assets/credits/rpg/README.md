# 3D asset credits

The project source archive includes original files, pinned revisions and processing manifests. Runtime models are processed game assets; they are not the unmodified source downloads.

## Hogwarts school architecture

- Maarten Coppens, [Hogwarts project](https://www.maartencoppens.be/projects/hogwarts), [Story-map source](https://github.com/maartencoppens/Story-map), revision `ab51f0e8c04b745303f6e5f2a905d6555f07d608`. Selected school geometry is adapted with new open arcades, near-field details, game coordinates and replacement materials. See the complete [MIT notice and original project disclaimer](maarten-coppens-mit.txt).
- Shahriar Shahrabi / IRCSS, [Blender Geometry Node French Houses](https://github.com/IRCSS/Blender-Geometry-Node-French-Houses), revision `b49b3c1dca15a57f3696e23c6f3ba8badf1fa6a3`. Native Gothic stone profile geometry is isolated from the MIT Blender source library. See the complete [MIT notice](shahriar-shahrabi-mit.txt).
- Original third-party materials and separately credited props embedded in the school reference model are excluded from the processed runtime assets.

## Characters and effects

The Anime player character uses the project's accepted character reference, generated Tripo mesh and Meshy rig, with local Blender animation and hand processing. Enchanted Armour, Bewitched Spellbook and Courtyard Warden models, their wear maps, and runtime spell effects are created for this project. Their processing records are in the editable source archive.
